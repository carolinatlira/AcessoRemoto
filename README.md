# AcessoRemoto
Um guia básico de como fazer acesso remoto em computadores e celulares.

Principais ferramentas:
# Anydesk
  Fazer o download em https://anydesk.com/pt
  Confira abaixo a tela inicial do aplicativo:

  Siga para a instalação, a versão utilizada no momento do teste foi a 9.7.
  <img width="959" height="505" alt="Captura de tela 2026-07-28 165407" src="https://github.com/user-attachments/assets/4fdc11ca-f91f-42ac-8637-bb87cc079e7b" />
  Você poderá realizar um acesso remoto supervisionado ou não supervisionado. No caso do supervisionado, é necessário uma pessoa presente na outra máquina para conceder o acesso. Já no modo não supervisionado, é necessário configurar uma senha como na imagem abaixo:
  <img width="959" height="504" alt="Captura de tela 2026-07-28 165650" src="https://github.com/user-attachments/assets/fd81f171-5817-4bab-9097-50534673bcd0" />
  É possível fazer o acesso remoto tanto de celulares quanto de computadores, interagir com os aplicativos e enviar documentos ou arquivos. Coloque o endereço remoto da máquina a ser acessada no lugar indicado na imagem abaixo.
